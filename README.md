# atelier-journal

架空ブランドの世界観を、大きな写真と文字の誌面のような配置で見せる、雑誌風のおしゃれなWebサイト。

- 仕様：[docs/spec.md](docs/spec.md)
- 見た目：[docs/design.md](docs/design.md)

[ai-dev-template](https://github.com/Gaku1205/ai-dev-template) の工場で、1行のメモ（架空ブランドの、写真を雑誌みたいに見せるおしゃれなサイト）から作ったサービスです。Issue を書くと、AI が清書・実装・レビュー・マージまで進めます（[docs/pipeline.md](docs/pipeline.md)）。
