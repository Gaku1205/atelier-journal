# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

架空ブランドの世界観を、大きな写真と文字の誌面のような配置で見せる、雑誌風のおしゃれなWebサイト。（元のメモ：架空ブランドの、写真を雑誌みたいに見せるおしゃれなサイト）

## 前提

- 使う人・使う場面（デザイン担当の分析。推定を含む）：
  - 使う人：架空のブランド USUZUMI の世界観に惹かれた人。服を買う前に、まずブランドの空気を「読んで」知りたい人
  - 場面：Instagram などから流れてきて、スマホで縦にスクロールしながら雑誌をめくるように眺める。気に入ったらパソコンでもう一度じっくり読む
  - 目的：今号の読み物を読み、品々（型番・素材・価格）と凪浦の店の情報を知る
- 技術：Next.js（App Router）＋TypeScript、テストはVitest

## 画面

### トップページ（`/`、1 ページだけ）

季刊誌 USUZUMI JOURNAL No.07「余白を、まとう。」を、上から下へめくるように読む 1 ページ。見た目は `docs/design.md`、中身（号数・目次・読み物・品々・対話・店・お知らせ・奥付）は `src/lib/issue.ts`。

**並び**（上から）

1. **表紙**（`#cover`）：縁に紙色を残した全面の図版（夜明け前の海）。左上に「季刊 USUZUMI JOURNAL」、その下に誌名「Usuzumi」、右上に No.07、右端に縦組みの特集名「余白を、まとう。」、左中ほどに英語の副題「The Quiet Season」と「AUTUMN / WINTER 2026」、左下に目次の抜粋（p.04・p.18・p.30・p.40。720px 以下では最初の 3 行）、右下に紙色の箱のバーコード「No.07 / 店頭で無料」。目次の抜粋の行を押すと、その頁へスクロールする
2. **目次**（`#contents`、p.02）：左に「Contents ／ 目 次」と前書きと小さな図版（Fig.00）。右に 5 行（ページ番号・題・小見出し・英題）。行を押すとその頁へスクロールする。どれかの行を指す（またはキーボードで選ぶ）と、ほかの行が 0.32 の濃さに薄くなる
3. **読み物1**（`#feature-01`、p.04「灰色の朝に、針を持つ。」）：左に画面の左端まで断ち落とした大きな図版、右に縦組みの題・リード・署名・本文（1 文字目は弁柄のドロップキャップ。題は文の間、上の帯の下に潜らず画面に残る）。その下に英文の引用と和訳、さらに小さな図版と、画面の右端まで断ち落とした大きな図版を互い違いに置く
4. **読み物2**（`#feature-02`、p.18「麻を、冬に着る。」）：全面の図版（麻の生地）が画面に貼り付き（sticky）、その上を紙色のパネル 2 枚が下から流れてくる。1 枚目は縦組みの題と本文、2 枚目は「重ねるための七つの決まり」（1 行ごとに右へずれる詩の段差、番号は弁柄の漢数字）。図版の上に英字の大見出し「Linen / in Winter」。最後に引用「Wear the space between. ／ 余白を、まとう。」
5. **品々**（`#pieces`、p.30）：左に見出し「Pieces ／ 品 々」と説明（スクロールしても画面に残る。1024px 以下では残さない）。右に 4 品を 2 列で並べ、偶数番目は下へずらす。各品は図版・型番（新しい物は「new」）・名前・素材と色・価格（「¥38,500」の形）
6. **対話**（`#talk`、p.40、夜の頁）：地が墨になる。大見出し「Hands / remain.」（2 行目は字下げして弁柄（夜））、和題、話し手、夜の店の図版。右に発言を「名前｜本文」の行で並べる
7. **店・お知らせ・奥付**（`#store`、p.46）：縦の罫で左右に分ける。左に店の情報（所在地・営業・定休日・受け付け）とお知らせ（日付は「2026　10　21」の形、新しい物は「new」）。右に各頁への大きな英字のナビと奥付（発行・編集・図・号）。最後に誌名「Usuzumi」を画面幅いっぱいに

**上の帯**（画面の上に固定）

- 左に「USUZUMI」（押すと表紙へ）、中央に「USUZUMI JOURNAL No.07 — 2026 秋冬」（720px 以下では出さない）、右に 目次・読み物・品々・店（押すと各頁へなめらかにスクロール）
- 表紙が帯の下に見えている間は、地が無く、文字を差分合成（`mix-blend-mode: difference`）で重ねる。表紙が帯の下から抜けたら、紙色の地と墨の下罫になる（`data-past-cover="true"`）

**ノンブル**（右下に固定）

- 各頁は `data-folio`（ページ番号）と `data-folio-title`（題）を持つ。画面の上から 70% の位置より上に頭が来ている頁のうち、いちばん下の頁を「いま開いている頁」とし、「p.04 / 48　灰色の朝に、針を持つ。」の形で出す（720px 以下では題を省く）
- 表紙の上（どの頁の頭も 70% の位置に届いていない）では出さない
- 判定は `src/lib/format.ts` の `pickFolio`、表記は `formatFolio`

**動き**（`IntersectionObserver` と CSS だけ）

- JS が動いたときだけ（`<html class="js">`）動かす。JS が無いときは最初から全部見せる
- 表紙：図版が 1.08 → 1 に 2.4s で縮み、誌名・副題・特集名が順に少し遅れて浮き上がる
- `data-reveal` を付けた塊は、画面に入ると下から 24px・透明から 0.9s で出る。中の図版は 1.08 → 1 に 1.6s で縮む
- `prefers-reduced-motion: reduce` のときは、動き・なめらかなスクロールを全部止めて、最初から見せる

**幅ごとの組み方**

- 1025px 以上：12 段のグリッド。見出し左 4 段＋中身右 7 段、読み物は図版左 7 段＋文右 4 段
- 1024px 以下：見出しを上、中身を下に
- 720px 以下：1 段に積む。ただし読み物1の後半の「小さな図版と大きな図版の互い違い」と、品々の 2 列と下へのずれは残す。横にはみ出さない

**図版**

- すべて `src/components/Plate.tsx` の SVG。どれも `role="img"` と `aria-label`（何が写っているか）を持つ
